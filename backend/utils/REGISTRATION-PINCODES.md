# Registration PIN data

`registrationPincodes.json` contains distinct Andhra Pradesh and Telangana PIN
codes extracted from the 2024 snapshot in
[pincodes-india](https://github.com/dropdevrahul/pincodes-india/tree/d26206918dd2fb9f155bfba18de0421bd5fa0ca8),
which identifies its source as the
[Government of India PIN directory](https://www.data.gov.in/resource/all-india-pincode-directory-till-last-month).
The official directory was not accessible when this snapshot was selected.
The snapshot may be outdated and contains 17 PINs listed for both states; those
PINs are accepted for either state. Refresh and verify this file against a
current official directory when available.
